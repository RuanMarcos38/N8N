# Estado da versão para VPS

Frontend e backend foram adaptados para executar no mesmo serviço Node.js 24, com banco SQLite persistente, login por senha, sessões, convites e arquivos assinados. Consulte EASYPANEL.md.

Integrações externas exigem credenciais e validação própria. A ausência de credenciais é informada; não há simulação de envio, pagamento ou geração de IA. Não houve migração de dados/contas do AppDeploy.

# R2R SalesOS

Frontend React e backend Node.js 24 independentes do AppDeploy, preparados para Docker e EasyPanel. O Dockerfile da raiz constrói a aplicação em `r2r-salesos/app` e serve interface e API na porta 3000.

Consulte [Implantação no EasyPanel](docs/EASYPANEL.md) para configuração, primeiro acesso, persistência e integrações.

A versão anterior publicada no AppDeploy permanece independente. Contas e dados dessa versão não são importados automaticamente. Os modelos n8n continuam em `integrations/n8n`.
